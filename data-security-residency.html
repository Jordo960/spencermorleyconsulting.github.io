Data Security & Residency

Last verified July 18, 2026 · Spencer Morley Consulting, Edmonton, Alberta

Municipal clients working with Spencer Morley Consulting reasonably want to know where their resident and program data actually lives, and what protects it. This page sets out the infrastructure behind SMC's client-facing tools — including our online resident survey programs — in plain terms, with sources so it can be independently verified.

Where the data is hosted

SMC's client-facing tools, including resident survey programs built for Alberta municipalities, run on OVHcloud Virtual Private Server (VPS) infrastructure located in OVHcloud's data center in Beauharnois, Quebec — inside Canada.

Certifications that apply to that infrastructure

These certifications belong to OVHcloud, SMC's infrastructure provider, and apply at the data-center level rather than to Spencer Morley Consulting as a firm. We list them here because they describe the environment our client tools actually run in:

  • ISO/IEC 27001:2022 — information security management, held by OVHcloud company-wide, across all data centers, since 2013.
  • ISO/IEC 27017:2015 and ISO/IEC 27018:2019 — cloud-specific security controls and protection of personal data in the cloud.
  • ISO/IEC 27701:2019 — personal data processing management.
  • SOC 2 Type II — audited under AICPA/SSAE 18 standards. OVHcloud's published SOC 2 scope names Dedicated Servers, Public Cloud Compute Instances, and Hosted Private Cloud specifically; SMC does not claim SOC 2 attestation for the VPS product line on its own, only that VPS runs within the same certified facilities.
We're deliberately precise about scope here: OVHcloud's HIPAA and PCI DSS attestations are named for other product lines, not standard VPS, so we don't claim them for our own hosting. If a project has a specific compliance requirement (HIPAA, PCI, or otherwise), tell us — we'll confirm directly with OVHcloud rather than assume.

Canadian data residency

Because SMC's tools are hosted in OVHcloud's Beauharnois, Quebec facility, resident and client data collected through them stays physically within Canada by default. This is relevant to municipal clients navigating Alberta's ATIA/POPA, BC's FOIPPA, Ontario's MFIPPA, or Manitoba's FIPPA, where data residency and cross-border disclosure are recurring questions. OVHcloud, as a non-U.S. provider, positions its infrastructure as sitting outside the reach of extraterritorial laws such as the U.S. CLOUD Act — that is OVHcloud's own compliance positioning rather than an independent legal opinion SMC has commissioned, and municipalities with a specific jurisdictional requirement should raise it with us directly before an engagement begins.

What SMC is responsible for

Security here is a shared responsibility. OVHcloud secures the physical data center, network, and hypervisor layer. SMC is responsible for everything above that: serving our tools over HTTPS/TLS, restricting access to survey and client data to the project team, and agreeing data handling and retention terms with each client before a project starts.

Frequently asked

How does SMC secure client and resident data?

Via OVHcloud VPS infrastructure in Canada, HTTPS/TLS on all client-facing tools, and access limited to the SMC project team — see "What SMC is responsible for" above.

Where exactly is the data stored?

OVHcloud's data center in Beauharnois, Quebec, Canada.

Is this the same as SMC's website hosting?

No — spencermorleyconsulting.ca itself is hosted separately, on IONOS WaaS WordPress. This page is about the infrastructure behind our client-facing tools, such as resident survey programs.
